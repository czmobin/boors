# فیلتر نمادهای بورس ایران

سیستم فیلتر هوشمند برای تحلیل قدرت خریدار و ورود پول در نمادهای بورس ایران

## ویژگی‌ها

- دریافت خودکار داده از API های TSETMC
- محاسبه قدرت خریدار و ورود پول حقیقی/حقوقی
- ذخیره‌سازی دوره‌ای داده‌ها در Excel (هر 5 دقیقه)
- فیلتر نمادهایی که قدرت خریدارشان نسبت به ابتدای روز رشد کرده
- گزارش‌گیری تفصیلی در شیت‌های جداگانه Excel

## نصب

### پیش‌نیازها

- Python 3.8 یا بالاتر

### نصب کتابخانه‌ها

```bash
pip install -r requirements.txt
```

## تنظیمات

### فایل `symbols.json`

لیست نمادهای مورد نظر را در این فایل قرار دهید:

```json
{
  "symbols": [
    {
      "name": "نماد غدیر",
      "insCode": "65197850030400728",
      "ticker": "نماد"
    },
    {
      "name": "نماد دیگر",
      "insCode": "کد نماد",
      "ticker": "نماد کوتاه"
    }
  ]
}
```

برای یافتن `insCode` نماد:
1. به سایت [TSETMC](https://tsetmc.com) بروید
2. نماد مورد نظر را جستجو کنید
3. `insCode` در URL صفحه نماد قرار دارد

### فایل `config.py`

تنظیمات پیشرفته:
- `UPDATE_INTERVAL_MINUTES`: فاصله زمانی بروزرسانی (پیش‌فرض: 5 دقیقه)
- `MIN_BUYER_POWER_GROWTH`: حداقل رشد قدرت خریدار برای فیلتر (پیش‌فرض: 10%)
- `EXCEL_OUTPUT_DIR`: پوشه ذخیره فایل‌های Excel

## استفاده

### اجرای معمولی (دوره‌ای هر 5 دقیقه)

```bash
python main.py
```

### اجرای یک بار

```bash
python main.py --once
```

### تغییر فاصله زمانی (مثلا هر 10 دقیقه)

```bash
python main.py --interval 10
```

### استفاده از فایل نمادهای دیگر

```bash
python main.py --symbols my_symbols.json
```

## خروجی

### فایل Excel

- هر روز یک فایل جدید با فرمت `bourse_data_YYYY-MM-DD.xlsx`
- هر اجرا یک شیت جدید با زمان اجرا (مثلا `09-30`)
- شیت ویژه `فیلتر_شده` برای نمادهای با رشد قدرت خریدار

### ستون‌های Excel

- **نماد**: نام نماد
- **کد**: insCode نماد
- **زمان**: زمان دریافت داده
- **حجم_خرید_حقوقی**: حجم خرید حقوقی
- **حجم_فروش_حقوقی**: حجم فروش حقوقی
- **تعداد_خرید_حقوقی**: تعداد معاملات خرید حقوقی
- **تعداد_فروش_حقوقی**: تعداد معاملات فروش حقوقی
- **ورود_پول_حقوقی_میلیون**: ورود/خروج پول حقوقی (میلیون تومان)
- **ورود_پول_حقیقی_میلیون**: ورود/خروج پول حقیقی (میلیون تومان)
- **قدرت_خریدار**: نسبت خرید به فروش حقوقی
- **سرانه_خرید_حقوقی_میلیون**: میانگین حجم هر معامله خرید حقوقی
- **سرانه_فروش_حقوقی_میلیون**: میانگین حجم هر معامله فروش حقوقی
- **ورود_پول_خالص_میلیون**: خالص ورود پول (میلیون تومان)

### ستون‌های اضافی در شیت فیلتر شده

- **رشد_قدرت_خریدار_درصد**: درصد رشد نسبت به ابتدای روز
- **قدرت_خریدار_اولیه**: قدرت خریدار در ابتدای روز

## نکات مهم

1. **زمان بازار**: برنامه را در ساعات معاملات بورس (9:00 تا 12:30) اجرا کنید
2. **تعداد نمادها**: با تعداد زیاد نماد (100+)، زمان اجرا ممکن است طولانی شود
3. **محدودیت API**: برای جلوگیری از مسدود شدن، بین درخواست‌ها تاخیر 0.5 ثانیه وجود دارد
4. **داده اولیه**: اولین اجرای روز به عنوان مبنای مقایسه ذخیره می‌شود

## توسعه بیشتر

- افزودن نمودار نقطه‌ای روند قدرت خریدار

- اتصال به تلگرام برای اطلاع‌رسانی
- داشبورد وب برای نمایش لحظه‌ای
